# P66 multi-domain scaleout

User request: accelerate real multiprocess synthesis and filtering across more
domains, worlds and trainable long tasks with an MRCR-like registered pipeline.

## Success criteria

- Register independent authenticated source jobs behind the shared source-role
  runner; pin scripts, configs, inputs, trust wrapper and public trust identity.
- Add at least two domains beyond Finance and CodeForge when their durable
  source actions permit candidate generation.
- Preserve source-group train/eval isolation and count source worlds, unique
  contexts, semantic tasks and rows separately.
- Generate only natural full records. No padding, cloning, unrelated capacity,
  exact-range relabeling, or silent use of diagnostics as training rows.
- Measure full-chat and source-body 64/128/256 capacity separately; retain exact
  numeric ranges as a second statistic.
- Run latest-only, short-window, compact/complete-record and remove-one controls;
  rejected or authorization-held cases remain visible in receipts.
- Produce native build/validate/replay receipts and a local candidate handoff;
  strict, release and production states remain separate gates.

## Active tracks

1. Held — IETF: multi-family requirement/version tasks from existing
   authenticated authorized RFC sources, with multiprocessing and source split.
2. Complete — Cyber: multi-world vulnerability/advisory/remediation tasks
   from existing authenticated authorized sources.
3. Complete — inventory organizer: mapped Macro, ResearchLab, GovInfo-compatible
   and technical-document routes to exact executable source jobs and blockers.
4. Complete — root: reconciled outputs into a registered admitted-source catalog,
   reran native validators, measured distribution and built the signed handoff.

## Closeout

The four-domain exploratory wave executed 411 views over 195 canonical tasks,
but scientific admission retained only the corrected 36-row Cyber batch. IETF
was held for a counterfactual/question conflict and prompt key-order mismatch;
Macro was held because answer-irrelevant relation blocks created its length
bands; ResearchLab was held for structural-source delta amplification and
unmeasured shortcut controls. GovInfo remained on its P65 authorization hold.

The signed consolidated candidate handoff contains the 164-row P65 handoff plus
36 Cyber rows: 200 rows, 132 train/68 eval, 15 included worlds, 120 contexts and
3 training domains. Full-chat capacity bins 64/128/256 are 24/73/103; exact
numeric ranges are 13/14/14 plus 159 other-long rows. Strict, training-release,
framework-preprocessing and production eligibility remain false.

The current admitted catalog contains corrected Cyber only and passed native
replay at `reports/p66_pipeline_admitted_v1/PIPELINE_RECEIPT.json`. The signed
handoff is `data/candidates/p66_multidomain_handoff_v1/BUILD_RECEIPT.json`.
