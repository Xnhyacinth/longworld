## 5. 探针结论边界(用户裁定的收紧表述,永久保留)

| 已测 | 支持 | 不支持 |
|---|---|---|
| 全量求解器复核 | 声明语法内答案可恢复 | 自然语言模型无其他捷径 |
| matched-entity 0 重现 | 指定扰动下答案依赖内容 | 一切答案先验/条件捷径已消除 |
| 分类器不优于先验 | 所测特征/模型/划分无预测力 | 更强模型无法利用捷径 |
| 门双口径过 | 项目风险约束满足 | 训练不会协议捕获 |
| 三格式 gold 一致 | 跨表达共享答案标签 | 必然跨格式泛化 |

## 6. 启动顺序(执行中)

1. **链路预检**(小子集:短+128K × L1-L4 × 可答/不可答 × 含非 json 表达):
   少量更新验证 loss/有效 token 统计/ckpt 导出加载/无模板塌缩/eval 协议不变。
2. **A 臂 SFT**:未退化 Base 起步;曝光 10%/25%/50%/100%(248 步@1ep 为观察
   上限,是否到 1.5ep 由曲线决定);每档 ckpt 评测。
3. **B 臂 SFT**(独立登记):同预算口径重推导(402 步@1ep 基线,含短锚后重算)。
   若 B>A 只先说"组合改进有效",归因留给匹配消融。
4. 评测五组指标(内部族×长度/紧凑证据对照/跨格式与规则/真实长文/短任务保持),
   内容正确与格式正确分开报;真实长文评测(MRCR/GraphWalks/对齐协议)**现在
   即入**,不等 C1 训练源。
5. 停止标准按用户表预写;负结果保留。
