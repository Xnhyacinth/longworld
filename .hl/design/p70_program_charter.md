# P70 持续执行章程（goal 文档）

Status: active. 本文是 P70 阶段的持续目标锚点：所有子任务对照本文的目标
编号与验收门推进。完成一项勾一项；发现矛盾时**改本文**而不是绕开。

## 总目标（G70）

在 P69 已验证的编译器地基上，产出一个**规模波级**的多能力长文数据银行，
通过塌缩门与独立求解器复核，为第一次受控训练实验（P67 的 A/B 消融）准备
数据侧的全部前提。数据必须同时满足：多样性、正确性、真实长依赖、可训练
性（一问一行 reader 契约 + 按行数推导的训练预算）。

## 分目标与验收门

### G70-1 能力覆盖扩到 L1/L2/L3/L4 四层（当前只有 L2 切片 1）
- 现状：filter_aggregate / group_compare / join_lookup = L2；workflow=L3 已
  重构；rule_learning=L4 是单仿射族。
- 目标族（对齐配方 §1 的 F1-F7）：
  - **F1 别名定位**（L1）：同构正负例、绑定交换翻转答案
  - **F2 集合完整性**（L2）：列出所有命中 + 未覆盖区插入新命中翻转答案
  - **F3 as_of/版本状态**（L3）：事件时间线 + as_of 截断 + 撤销传播
  - **F7 规则 holdout**（L4）：≥2 个新规则结构（阈值分类、奇偶多数），
    按规则结构切分 train/eval——不是按 seed
- 验收：每族有独立求解器、干预验证、契约钉定（P0-1 模式）、20+ 措辞、
  ≥8 个结构各异 answer 形态；全部进测试。

### G70-2 表达多样性：三 renderer（当前只有 JSON 记录）
- 目标：同一 TaskSpec 渲染为 (a) JSON 行（现状）(b) 自然语言记录
  （散文句式每行一条）(c) 表格/CSV 文本。**同一程序跨格式验证**——
  这是"学会操作还是学会 JSON"的判别实验基础（评审实验 A 的材料）。
- 验收：跨格式同 gold 复核；格式标注进 receipt；no-JSON 行占比可配比。

### G70-3 验证器提速（当前 97% 时间在重复 parse_context）
- 已定位：validate_bundle 每次 solve_visible 都从字符串重解析整个上下文
  （O(K×L) 次 json.loads）。
- 目标：解析一次传结构，remove-one 用行级删除+增量重解；预期 ≥10×。
- 验收：吞吐复测报告进 receipt；语义不变（同 bundle 验证结果一致）。

### G70-4 P70 规模波银行 + superset 池（alchemy 的单源直采模式）
- 目标：superset 池 ~6-10k 语义任务（G70-1 族全量），**hash(id) 前缀
  确定性分层采样**出臂：主臂（~5000 行）、机制消融臂、格式消融臂
  （JSON vs 混合）、L/K/H 各轴的极端单元。臂间共享 stratum 行（paired）。
- 验收：`--gate` exit 0（按行数推导的预算）；独立求解器 100% 复核；
  split 按 seed 世界隔离且 L4 按规则结构隔离；每源曝光≤50。

### G70-5 联网调研循环（持续）
- 每轮开工前：定向调研一个主题（本轮：π² 的推理链构造、LongCrafter 的
  证据图→自然语言渲染、InfiniteScienceGym 的不可答生成、Oolong 的全局
  分布问题），把**可执行机制**（不是概念）带回来进设计。
- 验收：每轮调研产出 ≤1 页机制摘要进配方文档附录，标注"调研结论"。

### G70-6 可训练性闭环（训练侧前提，不是训练本身）
- 短锚：下载 DocQA-RL-1.6K（apache-2.0）并测实际 token 份额；LongAlign
  无许可证标——不用，找替代或声明上限。
- 训练预算推导器：按行数×epoch 红线输出 steps 建议（P67 纪律的自动化）。
- 验收：P70 波的 manifest 里带 budget_recommendation 块。

### G70-7 正确性与诚实标注（红线，持续）
- strict_long_dependency_verified / model_utility_measured /
  production_eligible 全 false；infeasible 如实记录；不可答任务（若造）
  必须是"两个合法世界补全答案不同"型，不是缺记录哨兵。

- 不为过门而调门；门阈值改动必须走数据依据
- 不把 padding 计入语义规模；不放松任何 fail-closed 检查
- 不引入 pandas/duckdb/SQL 依赖（保持纯 Python 执行器）
